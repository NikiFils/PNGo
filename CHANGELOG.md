# Changelog

Все значимые изменения проекта фиксируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.0] — 2026-10-08

### Добавлено
- Drag & drop конвертация PSD / PSB / TIFF / JPG / GIF / WEBP / BMP / TGA / ICO и др.
- Сохранение PNG с прозрачностью рядом с исходным файлом
- Многостраничный TIFF и анимированный GIF — постраничное сохранение
- Настройки прозрачности и цвета фона
- Сжатие PNG (0–9), ресайз по длинной стороне, обрезка пустых краёв
- Режимы при существующем PNG: перезапись / пропуск / автонумерация
- Суффикс к имени файла
- Тултипы с возможностью отключения
- «Всегда поверх окон», запоминание размера и позиции окна
- Диалоги «Помощь» и «О программе»
- Прогресс-бар и многопоточная обработка
